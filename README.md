# Push to Talk

Микрофон по кнопке для Windows: пока держишь клавишу — микрофон работает, отпустил — заглушён.
Приложение живёт в трее и не мешает.

[English version →](README.en.md)

![Push to Talk](screenshot.png)

## Что умеет

* Микрофон заглушён, пока не зажата клавиша push-to-talk (по умолчанию **HOME**).
* Клавиша меняется прямо в окне: «Изменить» → нажать нужную клавишу (Esc — отмена).
* Push-to-talk можно выключить — тогда микрофон всегда активен.
* Блокировка клавиши: с включённой галкой клавиша не попадает в игру или редактор.
* Автозапуск с Windows — галочка в правом нижнем углу окна.
* Трей: значок показывает состояние (активен / заглушён / нет устройства), один клик левой
  кнопкой открывает окно, правый клик — меню (открыть настройки, включить/выключить PTT, выход).
* Индикатор уровня сигнала и имя устройства записи — видно, что микрофон действительно слышит.
* Язык интерфейса RU / EN — кнопка в футере, влияет и на меню трея.
* Крестик, сворачивание и Esc прячут окно в трей; полный выход — «Выход» в окне или в меню трея.
* Окно компактное, 16:9: утилита в основном работает в трее, размер подобран так,
  чтобы открыть, проверить и закрыть.

## Требования

Windows 10 или 11. Нужен компонент WebView2 Runtime — на Windows 10/11 он уже есть вместе
с Edge. Больше ничего: среда .NET и интерфейс находятся внутри exe.

## Установка

1. Скачать `PushToTalk.exe` из [последнего релиза](../../releases/latest).
2. Запустить — приложение появится в трее (значок микрофона).
3. При первом запуске микрофон заглушён: он включается, пока держишь клавишу PTT.

## Настройки и лог

* `%APPDATA%\PushToTalk\config.ini` — клавиша, включён ли PTT, блокировка клавиши, язык.
  Файл можно править и вручную, но обычно всё меняется прямо в окне.
* `%APPDATA%\PushToTalk\log.txt` — запуск, нажатия клавиши PTT, переключения микрофона, ошибки.
* Автозапуск: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, значение `PushToTalk`.

## Как это работает

Приложение подписывается на клавиатуру (WH_KEYBOARD_LL), поэтому видит клавишу PTT в любой
программе, а не только когда окно в фокусе. Пока клавиша нажата, с микрофона снимается
заглушение через CoreAudio (устройства связи и по умолчанию), после отпускания заглушение
возвращается. Раз в секунду состояние микрофона сверяется — изменения, сделанные другими
программами, тоже видны.

## Сборка

Нужен .NET SDK 8 (официальный от Microsoft) и команда:

```
dotnet publish -c Release -r win-x64
```

На выходе один exe, внутри которого и логика, и интерфейс. Интерфейс лежит в `ui/` —
его можно открыть в браузере (`ui/preview.html`) и посмотреть без сборки.
