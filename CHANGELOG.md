# История изменений

## 2.1.0 — 17 октября 2026

* новый режим «Переключение одним нажатием»: одно нажатие клавиши включает микрофон, следующее —
  выключает (прежнее поведение «держи и говори» осталось, переключатель в настройках);
* при выходе из программы микрофон возвращается в то состояние, в котором был до запуска
  (в том числе при нештатном завершении);
* смена клавиши: таймаут 8 секунд, отмена по клику вне окна и кнопкой «Отмена», Ctrl/Alt/Shift/Win
  назначить нельзя;
* клавиша, отпущенная на защищённом экране (UAC), больше не оставляет микрофон открытым;
* окно всегда выходит на передний план по клику по значку в трее;
* автозапуск: при входе в Windows окно не показывается, приложение остаётся в трее; `Esc`
  сворачивает окно в трей, когда окно программы в фокусе;
* репозиторий снова собирается: файлы интерфейса перенесены в `src/app/`, добавлены иконки
  и шрифты, которых не хватало;
* лог не обнуляется при запуске (прошлый запуск остаётся в `log.prev.txt`).

## 2.0.0 — 17 октября 2026

Приложение переписано на C#/.NET 8 + WebView2: интерфейс — HTML/CSS (тёмная тема, карточки,
переключатели, свой заголовок окна), логика нативная.

* окно в пропорции 16:9, компактное — утилита живёт в трее;
* индикатор уровня сигнала и имя устройства записи;
* значок в трее меняется по состоянию микрофона, один клик открывает окно;
* настройки и лог переехали в `%APPDATA%\PushToTalk\`: прежний `config.ini` подхватывается,
  ключи (`key`, `ptt`, `block`, `lang`) те же, автозапуск пишется в то же значение реестра;
* функции прежней версии сохранены полностью: клавиша PTT работает в любой программе,
  блокировка клавиши, включение и выключение PTT, автозапуск, RU/EN, выход только через трей.

## 1.0.0 — 16 октября 2026

Первая публичная версия: C/Win32, один exe без зависимостей.
Микрофон по кнопке (по умолчанию HOME), переназначение клавиши, блокировка клавиши,
выключение PTT, автозапуск, трей, RU/EN.
